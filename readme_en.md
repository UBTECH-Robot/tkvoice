# tkvoice

Offline voice interaction service.
The wake-up word "Walker Walker" can interrupt the current response
## Installation (Internet connection required, no internet connection needed after installation) #Copy to C1

scp tkvoice_1.0.0.tar walker@新机器人IP:/debug/
cd /debug/
mkdir tkvoice
tar -xvf tkvoice_1.0.0.tar -C tkvoice
cd /debug/tkvoice


## Installation

bash /debug/tkvoice/setup_robot.sh
